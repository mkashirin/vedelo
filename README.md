# Vedelo

**Vedelo** (Vehicle Detection with YOLO) is trained on the
[Vedelo Dataset V1](https://huggingface.co/datasets/mkashirin/vedelo-dataset-v1).

## System Requirements

To build `vedelo-cli` and run Vedelo TorchScript models, ensure you have:
* An **x86_64** machine running a **Debian-based Linux distribution** with a **CUDA-compatible GPU**, and `build-essential` installed;
* [Rust toolchain](https://rust-lang.org) (compiler, package and project manager);
* [uv](https://docs.astral.sh/uv/) — Python package and project manager;
* [`just`](https://just.systems/) command runner.
